REX MCP · Custody for coding agents

Your agent says it’s done. Make it prove it.

REX MCP is a local stdio bridge into REX custody. Your agent still does the work — inside scoped workspaces, on five-minute leases, with sealed evidence and signed receipts. What REX adds isn’t creativity. It’s the inability to fake having done the work.

How custody works

Trust the record, not the agent.

Most agent tools take the agent’s word for it. REX doesn’t. Six custody events stand between your agent and the word “done” — each one recorded, each one checkable.

task.opened

A durable task record

Every run gets a task with a resume handle. Kill the process, lose the machine — the task survives, and you pick it up where it stopped.

workspace.granted

A fenced workspace

The agent receives capabilities for exactly one workspace. Outside it, every touch is denied — not warned about, denied.

lease.heartbeat

A five-minute leash

Leases expire after five minutes. The agent heartbeats to stay alive, or the task stops. No silent runaways burning tokens at 3 a.m.

evidence.sealed

Proof before “done”

Completion claims must cite sealed evidence. A claim with no proof is rejected at the gate — the task cannot complete on vibes.

redteam.verdict

An adversary reads it

Before anything is promoted, a red-team review tries to break the work. It ships only if it survives the attack.

receipt.signed

A signed receipt

The task closes with a signed, replayable receipt: who did what, with what evidence, proven when. Audit it any time.

The receipt

Seal one yourself.

The ledger above is a demonstration, not REX output. But the shape is real: press the button and every event digests into one hash — the same shape as a custody receipt, minus the cryptography.

Demo digest of the six events

A real REX receipt carries an Ed25519 signature over canonical JSON and can be replayed offline. This page computes a non-cryptographic demo hash in your browser — nothing leaves the page, nothing is claimed.
