# Tier-1 mock matrix dry-run + native cross-check (2026-09-20, MOCK ONLY - NOT PUBLISHABLE)

Everything here used mock_rex_bench.py (deterministic stand-in, no model).
These numbers validate the pipeline only; they say nothing about any model.

## Full matrix drill
- 6 suites x 3 tasks x 3 modes (raw/simple/ultra) x 2 seeds = 108 runs.
  Suites: evalplus-humanevalplus, evalplus-mbppplus, cruxeval-output,
  bigcodebench-hard, ds1000, livecodebench-release_v6 (release_v6, 3 tasks
  from test6.jsonl; suite sha256 e24d5b72...).
- plan.py generated byte-stable plans; orchestrate.py executed all 108 runs
  with checkpointing; aggregate.py produced per-env-group Wilson 95% and
  paired-bootstrap uplift intervals (report.json).
- Quota-stop drill: one ds1000 task marked MOCK_QUOTA_TASKS -> run recorded
  quota_stop, shard exited 75, quota-stop.json written with resume command.
  Resume completed the remaining runs without re-executing completed ones;
  the quota_stop record stays in results as excluded history.
