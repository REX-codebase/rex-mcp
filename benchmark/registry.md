# REX Ultra benchmark registry — legally reproducible open coding benchmarks

Built 2026-09-20 (Asia/Calcutta). Every row grounded in the primary source cited.
Purpose: pick suites for the raw vs Simple vs Ultra matrix on one pinned model
(Gemini 3.5 Flash-Lite, exact live identifier to be verified against the API
before the first scored run), ₹0 / free-tier only.

Verdicts: FEASIBLE = runs at zero cost in a plain Linux sandbox, scorer is
executable locally, dataset license permits reproduction. CONSTRAINED =
reproducible but with a flagged caveat. INFEASIBLE-HERE = legally fine but
needs resources this environment does not have.

## Tier 1 — FEASIBLE, primary matrix

### EvalPlus (HumanEval+ / MBPP+)
- Source: https://github.com/evalplus/evalplus (README, releases), license file https://raw.githubusercontent.com/evalplus/evalplus/master/LICENSE
- Pin: harness `evalplus==0.3.1` (released 2024-10-20). Dataset versions: HumanEval+ v0.1.x lineage; MBPP+ dataset upgraded to v0.2.0 on 2024-04-17 (broken tasks removed: 399 -> 378 tasks; ground-truth fixes for IDs 459/102/559 noted pre-v0.3.0).
- License: harness Apache-2.0. HumanEval+ derives from OpenAI HumanEval (MIT, https://raw.githubusercontent.com/openai/human-eval/master/LICENSE). MBPP+ derives from Google MBPP (CC-BY-4.0, https://huggingface.co/datasets/google-research-datasets/mbpp).
- Task counts: HumanEval+ 164; MBPP+ 378. Mini splits exist for smoke runs (HumanEval+ mini since v0.1.5).
- Contamination caveats: HumanEval (2021) and MBPP (2021) are heavily circulated in training data; treat absolute scores as upper bounds. EvalPlus adds ~80x more tests, which catches false passes but not memorization. Report alongside LiveCodeBench (temporal decontamination) for this reason.
- Resources: pure Python 3, stdlib + pip package; no docker required; per-task timeout configurable (conservative by default since v0.1.6). Scorer: `evalplus.evaluate --dataset humaneval|mbpp --samples <jsonl>` — executable, blind, test-based.
- Adapter fit: tasks are function-completion; prompt + entry point map cleanly to BenchTask; hidden tests staged at scoring time.

### LiveCodeBench (codegeneration scenario)
- Source: https://github.com/LiveCodeBench/LiveCodeBench (README), site https://livecodebench.github.io/
- Pin: dataset `release_v6` (1055 problems, May 2023 – Apr 2025); fine-grained tags v1..v6 and ranges (v4_v5 etc.) exist; `release_v1`=400, v2=511, v3=612, v4=713, v5=880, v6=1055. Harness repo commit to pin at fetch time.
- License: MIT (repo sidebar, README).
- Contamination caveats: designed for temporal decontamination; supports --start_date/--end_date windows. ERRATA.md documents known erroneous tests. For a 2026-era model, prefer a late window (e.g. v5/v6-era problems) to minimize leakage; record the exact window in every shard.
- Resources: Python (uv or pip), no GPU, no docker; scorer = modified APPS checker, executed locally via `python -m lcb_runner.runner.main --scenario codegeneration --evaluate --release_version release_v6`; `--continue_existing` supports resumable shards (fits daily-quota windowing).
- Adapter fit: stdin/stdout and call-based formats both exist; call-based subset maps to BenchTask most cleanly.

### BigCodeBench (Full 1140 / Hard 148)
- Source: https://github.com/bigcode-project/bigcodebench, dataset https://huggingface.co/datasets/bigcode/bigcodebench
- Pin: dataset revisions v0.1.0_hf..v0.1.4 (1.14k rows each; record exact revision at fetch). Hard subset released 2024-07-18 with `bigcodebench==0.1.8`.
- License: dataset Apache-2.0 (HF card); harness repo Apache-2.0 (GitHub sidebar).
- Task counts: Full 1140, Hard 148. Function-level, library-heavy (uses real PyPI libs).
- Contamination caveats: built 2024 from scratch-ish prompts, lower leakage than HumanEval but not temporally fenced; no per-date filtering. Note as moderate risk.
- Resources: scorer executes tests with a restricted runtime; docker recommended upstream but local eval supported; Python 3. Scorer: `bigcodebench.evaluate` — executable.
- Adapter fit: function-completion with entry_point; same adapter shape as EvalPlus.

### CRUXEval (input/output prediction)
- Source: https://github.com/facebookresearch/cruxeval (README + LICENSE)
- Pin: repo commit at fetch; single dataset release, 800 samples.
- License: MIT ("CRUXEval is MIT licensed", README §License).
- Task counts: 800 Python functions; two tasks (CRUXEval-I input prediction, CRUXEval-O output prediction).
- Contamination caveats: functions were machine-generated by Code Llama 34B then filtered, so leakage risk is lower than HumanEval; not temporally fenced.
- Resources: `pip install -r requirements-base.txt` suffices for scoring; Python 3.9+; no docker. Scorer executes candidate snippets against ground-truth outputs — executable, blind.
- Adapter fit: tasks are short completion/prediction; scoring is execution-based equality; maps to CommandSucceeds checks with staged harness.

### DS-1000
- Source: https://github.com/HKUNLP/DS-1000 (GitHub sidebar license)
- Pin: repo commit at fetch; "a simple list of 1000 problems" (README).
- License: CC-BY-SA-4.0.
- Task counts: 1000 data-science problems (pandas/numpy/sklearn/etc.; library info in metadata).
- Contamination caveats: sourced from StackOverflow-derived questions but modified to defeat memorization (per paper); still web-adjacent — moderate risk.
- Resources: needs pinned scientific-Python env (specific library versions matter); execution scorer; no docker.
- Adapter fit: completion-with-context; scoring runs inserted code + tests. Feasible but heaviest local env of Tier 1.

## Tier 2 — CONSTRAINED

### ClassEval
- Source: https://github.com/FudanSELab/ClassEval (README §License)
- Pin: repo commit at fetch; single release.
- License: code MIT; **data CC BY-NC 4.0** — non-commercial only. Reproduction for REX's own evaluation is fine; do not redistribute data inside a commercial artifact. Flagged for the open-source release.
- Task counts: 100 class-level tasks, 410 methods, avg 33.1 test cases/class.
- Scorer: executable test suites per class; three generation strategies (holistic/incremental/compositional) — pick holistic for comparability with single-shot raw mode.
- Verdict: FEASIBLE legally for internal benchmarking; CONSTRAINED for public redistribution.

### MultiPL-E
- Source: https://github.com/nuprl/MultiPL-E, LICENSE https://raw.githubusercontent.com/nuprl/MultiPL-E/main/LICENSE
- Pin: repo commit at fetch.
- License: BSD 3-Clause with Machine Learning Restriction (read the ML restriction clause before publishing scores commercially; internal benchmarking OK).
- Task counts: translations of HumanEval (164) and MBPP (sanitized) into 18+ languages.
- Resources: upstream uses podman/docker per-language containers; needs per-language toolchains. In this sandbox only the languages with native toolchains are feasible; full matrix is CONSTRAINED by environment, not license.
- Contamination: inherits HumanEval/MBPP leakage.

### Aider polyglot benchmark
- Source: https://github.com/Aider-AI/polyglot-benchmark (README), methodology https://aider.chat/2024/12/21/polyglot.html
- Pin: repo commit at fetch.
- License: repo MIT; exercise content copyright Exercism, used under Exercism's open-source licenses (per README) — redistribution caveats per-track.
- Task counts: 225 hardest Exercism exercises across C++, Go, Java, JavaScript, Python, Rust.
- Scorer: per-language test runners inside aider's harness (docker upstream). CONSTRAINED: harness is aider-shaped (diff/edit-format centric); adapting to rex-bench needs a translation layer, and non-Python toolchains add weight.

## Tier 3 — INFEASIBLE-HERE (legal, but not in this environment)

### SWE-bench Verified
- Source: https://www.swebench.com/verified, harness https://github.com/swe-bench/swe-bench, license https://raw.githubusercontent.com/swe-bench/swe-bench/main/LICENSE (MIT), blog https://openai.com/index/introducing-swe-bench-verified/
- Pin: `princeton-nlp/SWE-bench_Verified` HF dataset, 500 instances (human-validated subset: clear descriptions, correct test patches, solvable).
- License: MIT.
- Resources: official harness builds per-repo Docker images; needs docker daemon + tens of GB. This sandbox has no docker and 20 GB disk. Also each instance is a full repo issue-fix — token cost per task is high for free-tier windows.
- Verdict: registry-complete; execution deferred until a docker-capable machine exists. Not a license blocker.

## Cross-cutting registry notes
- HumanEval original: MIT (verified above); MBPP original: CC-BY-4.0 (verified above) — recorded for provenance; EvalPlus supersedes both for scoring rigor.
- Every shard must record: suite name, exact dataset version/revision, harness version/commit, license string, task ID list, model identifier, date window, seed(s), and scorer command. Aggregation only over completed raw/Simple/Ultra triplets within the same suite version.
- Publication caveat bundle: ClassEval (CC BY-NC), MultiPL-E (BSD+ML restriction), aider polyglot (Exercism per-track terms), DS-1000 (CC-BY-SA attribution+sharealike) — internal scores fine; bundled redistribution or commercial claims need review.
