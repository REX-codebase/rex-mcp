# Pixel-restraint thesis

The strongest direction is a calm continuous sheet, not a stack of cards. The task is the clear first action. State and result live in the same reading flow. Separators appear only where scanning needs them. History is a quiet text list below the current work.

## Three alternatives considered
1. Continuous sheet: a single 760px reading column with open sections and hairline separators. Selected because it removes container noise without hiding evidence.
2. Split workspace: composer left, receipt right. Rejected because it turns a simple agent into a dashboard and breaks the approved one-surface shape.
3. Command palette: one floating prompt over a blank canvas. Rejected because results and evidence become transient and harder to scan.

## System
- Near-black canvas, one subtly lifted task well, no gradients or glow.
- 32px display heading, compact 14-16px body, mono only for receipt/duration metadata.
- 8px control radii, 12px task-well radius; no pill inflation beyond the tiny preview status.
- Purple only for the primary action, focus, and active state. Green/amber only for verified/blocked.
- Motion is opacity/position under 180ms and removed for reduced-motion.
