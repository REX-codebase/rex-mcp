# Task input refinement

The prior boxed composer still read as a prebuilt card: border around the whole section, a separate underline textarea, a model row, and another divided examples row.

The refined input is one focused writing surface. The title moves outside the surface. The textarea and bottom controls share a single quiet field whose border strengthens only on focus. Examples become one short inline prompt beneath it. Monid is shown as planned, not live. The result is calmer because structure comes from type, spacing, and focus behavior rather than nested panels.
